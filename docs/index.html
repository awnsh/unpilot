Under the hood, the Copilot key is really a shortcut: it sends Win + Shift + F23. Quick Claude catches exactly that combination before Windows hands it to Copilot and opens Claude instead. Every other key works as normal, and uninstalling gives Copilot its key back.

How it works

Three keys. That's the whole app.

Quick Claude runs quietly in the background and listens for one key. Everything else happens in the popup.

Install

Thirty seconds to a better key.

One line in PowerShell, no admin rights. It starts with Windows and stays out of your way, which is more than Copilot ever did.

  1. Run the installerOpen PowerShell (not as admin) and paste: 
    irm https://raw.githubusercontent.com/awnsh/quick-claude/main/install.ps1 | iex
  2. Sign in onceIf the installer asks, connect Claude Code to your Claude account: 
    claude auth login
  3. Press the Copilot keyThat's it. Ask away.

You'll need

  • Windows 11 (or 10) with a Copilot key
  • A paid Claude plan that includes Claude Code (Pro or higher)
  • Claude Code: the one in the Claude desktop app works, or install it with irm https://claude.ai/install.ps1 | iex
  • The Claude desktop app, only for Ctrl+Enter

To uninstall

irm https://raw.githubusercontent.com/awnsh/quick-claude/main/uninstall.ps1 | iex
FAQ

Good questions.

Is this made by Anthropic?

No. Quick Claude is an independent, open-source project. It isn't affiliated with or endorsed by Anthropic. It talks to Claude through Anthropic's own Claude Code command-line tool, signed in to your account.

Does it cost anything?

Quick Claude is free. Questions use your existing Claude plan through Claude Code (Sonnet by default), the same as using Claude Code yourself. No API key needed.

Are my popup chats saved?

Enter chats aren't added to your Claude chat history. They vanish when the popup closes (Claude Code keeps a local transcript on your PC). Use Ctrl+Enter when you want a question saved in the Claude app.

How does it take over the Copilot key?

The Copilot key secretly sends Win+Shift+F23. Quick Claude uses a small keyboard hook to catch that one combination and open the popup instead. No other keys are touched, and uninstalling gives Copilot its key back.

Why is the glass a snapshot?

To get perfectly smooth rounded corners, the popup blurs a snapshot of your screen taken the moment it opens. If something moves behind it, like a video, the glass shows how it looked when you opened it.

Can I change the model or the shortcut?

Yes. It's one readable PowerShell file at %LOCALAPPDATA%\QuickClaude\quick-claude.ps1. Change Model or the system prompt near the top of the QuickWindow class, then sign out and back in.
