The Claude key

    
Mac has a Claude shortcut.
Now Windows has a Claude key.

    
On a Mac, the Claude app lets you press a keyboard shortcut and a little prompt bar floats up over whatever you're doing. Unpilot brings that same idea to Windows, and makes it one key: the Copilot key you weren't using anyway.

How it works

    
Describe. Paste. Press.

    

      
Describe it
Type what you want in plain words. This page figures it out on your device, and you can fine-tune the result.

      
Paste one line
Copy the command into PowerShell. It installs per-user (no admin rights), starts with Windows, and stays out of the way.

      
Press the key
The Copilot key does your thing now. Copilot never opens. Run a new line any time to change it.

    

    
Under the hood, the Copilot key is really a shortcut: it sends Win + Shift + F23. A tiny background script catches exactly that combination before Windows hands it to Copilot and does your action instead. Every other key works as normal.

  


  

    
FAQ

    
Good questions.

    

      
Is it really free?
Yes. No account, no subscription, no API keys. It's open source under the MIT license. The only thing that costs anything is the optional Claude popup, which uses your own Claude plan.

      
Does my request get sent to an AI service?
No. Your words are understood right here in the page by a built-in interpreter. If your Chrome has on-device AI (Gemini Nano) switched on, the page uses that for anything the interpreter doesn't recognize. That model also runs on your computer, so nothing is uploaded either way.

      
Can I make it act like a normal key, like right Ctrl?
Yes. "Act as another key" holds that key down for as long as you hold the Copilot key, so Copilot + C works as Ctrl + C. Right Ctrl, Alt, the menu key, and F13 to F24 all work.

      
How do I change it or undo it?
To change it, make a new one here and run the new line; it replaces the old setup. To remove it completely, run irm https://raw.githubusercontent.com/awnsh/unpilot/main/uninstall.ps1 | iex and the key goes back to opening Copilot.

      
Is it safe to paste into PowerShell?
The command downloads one installer from this project's GitHub and runs it. You can read every line first on GitHub. It only touches your user folder and Startup folder. "Run a command" actions run whatever you typed, so only use commands you understand.

      
Why Windows only?
The Copilot key only exists on Windows PCs, and the background script uses Windows features to catch it.

      
Who made this?
An independent open-source project. It isn't affiliated with Microsoft or Anthropic. Copilot is a trademark of Microsoft, and Claude is a trademark of Anthropic.
